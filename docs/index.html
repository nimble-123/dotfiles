.dotfiles

One command from a fresh Mac to my desk. Same repo for my personal and my work Mac.

$curl -fsSL https://raw.githubusercontent.com/nimble-123/dotfiles/main/bootstrap.sh | bash

Paste it into Terminal on a new Mac. It shows every change before applying it.

What the command does

It is safe to run again at any time. Nothing in your home folder changes until you say yes.

  1. Installs Xcode tools and HomebrewHomebrew needs admin rights once. On an account without them, the script stops and says what to ask IT for.
  2. Clones this repo with chezmoiIt asks for your email, whether this is the work Mac, and your SSH signing key.
  3. Shows the diff and waitsYou see every file that would change and decide whether to apply.
  4. Installs appsOne brew bundle run for the shared Brewfile plus the personal or work one.
  5. Writes dotfiles and macOS settingsShell, Git, SSH, Warp and VS Code config, then Finder, Dock and keyboard defaults.

What's inside

Plain chezmoi, plain Brewfiles, plain shell scripts. Nothing to learn beyond chezmoi itself.

Shell
zsh with zinit, starship, zoxide, direnv, fzf and nvm. Modern aliases for eza, bat, fd and rg.
Git
Every commit signed with an SSH key from 1Password at home or KeePassXC at work. No private key ever touches the disk.
Apps
Warp, VS Code with 110 extensions, btop, fastfetch, linearmouse and hazelnut.
macOS
Finder, Dock, keyboard, screenshots and save dialogs. A setting locked by MDM is reported, not fatal.
Safety
A public repo with nothing secret in it. gitleaks checks every commit.

Everyday commands

Change a file, check what would happen, apply it, push. The other Mac picks it up with one command.

Track a new filechezmoi add ~/.config/foo
Edit a tracked filechezmoi edit ~/.zshrc
See what would changechezmoi diff
Apply itchezmoi apply
Update the other Macchezmoi update
